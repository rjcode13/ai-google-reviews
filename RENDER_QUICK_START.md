# Quick Deployment Setup - Render.com\n\nStep-by-step guide to deploy your AI Google Reviews app to Render.com (best Railway alternative).\n\n## Prerequisites\n\n- GitHub account with your repository\n- Render.com account (free)\n- OpenAI API key\n\n## 📝 Step-by-Step Setup\n\n### Step 1: Create Render Account (2 minutes)\n\n1. Go to https://render.com\n2. Click \"Sign up\"\n3. Select \"GitHub\" to sign up with GitHub\n4. Authorize Render to access your GitHub\n5. You'll be redirected to Render dashboard\n\n### Step 2: Deploy PostgreSQL Database (3 minutes)\n\n1. Click \"+New\" → \"PostgreSQL\"\n2. Fill in:\n   - **Name**: `ai-reviews-db`\n   - **Database**: `ai_reviews`\n   - **User**: `postgres`\n   - **Region**: Choose closest to you\n   - **PostgreSQL Version**: 15\n\n3. Click \"Create Database\"\n4. Wait for database to be ready (~30 seconds)\n5. Copy the connection string (you'll need it later)\n\n### Step 3: Deploy Backend API (5 minutes)\n\n1. Click \"+New\" → \"Web Service\"\n2. Select your GitHub repository\n3. Fill in configuration:\n   - **Name**: `ai-reviews-api`\n   - **Environment**: `Node`\n   - **Build Command**: `cd apps/backend && npm run build`\n   - **Start Command**: `cd apps/backend && npm start`\n   - **Root Directory**: `.` (leave as is)\n\n4. Click \"Create Web Service\"\n5. Render will build and deploy automatically\n\n### Step 4: Configure Backend Environment Variables (3 minutes)\n\nOnce backend is deployed, go to its settings:\n\n1. In Render dashboard, click on the `ai-reviews-api` service\n2. Go to \"Environment\" tab\n3. Click \"Add Environment Variable\" and add:\n\n```\nNODE_ENV=production\nOPENAI_API_KEY=sk-xxx (your OpenAI key)\nOPENAI_MODEL=gpt-4\nOPENAI_TEMPERATURE=0.7\nOPENAI_MAX_TOKENS=500\nJWT_SECRET=your-very-secret-key-at-least-32-characters\nJWT_EXPIRY=7d\nDATABASE_URL=postgresql://user:password@host:5432/db (from Step 2)\nCORS_ORIGIN=https://your-frontend-url.onrender.com (leave for now, update later)\nPORT=3001\nLOG_LEVEL=info\n```\n\n4. Click \"Save Changes\"\n5. Backend will restart automatically\n\n**Save your backend URL** (looks like `https://ai-reviews-api.onrender.com`)\n\n### Step 5: Deploy Frontend (5 minutes)\n\n1. Click \"+New\" → \"Static Site\"\n2. Select your GitHub repository\n3. Fill in configuration:\n   - **Name**: `ai-reviews-web`\n   - **Build Command**: `npm install && cd apps/frontend && npm run build`\n   - **Publish Directory**: `apps/frontend/.next`\n   - **Root Directory**: `.` (leave as is)\n\n4. Click \"Create Static Site\"\n5. Render will build and deploy\n\n### Step 6: Configure Frontend Environment Variables (2 minutes)\n\n1. Go to `ai-reviews-web` service settings\n2. Click \"Environment\" tab\n3. Add environment variable:\n\n```\nNEXT_PUBLIC_API_URL=https://ai-reviews-api.onrender.com\n```\n\n4. Click \"Save Changes\"\n5. Frontend will rebuild and redeploy\n\n**Save your frontend URL** (looks like `https://ai-reviews-web.onrender.com`)\n\n### Step 7: Update Backend CORS (1 minute)\n\n1. Go to backend (`ai-reviews-api`) settings\n2. Go to \"Environment\" tab\n3. Find `CORS_ORIGIN` variable\n4. Update value to your frontend URL: `https://ai-reviews-web.onrender.com`\n5. Click \"Save Changes\"\n6. Backend will restart\n\n### Step 8: Run Database Migrations (2 minutes)\n\n1. Go to backend service\n2. Click \"Shell\" tab at top\n3. Run migrations:\n\n```bash\nnpx prisma migrate deploy\n```\n\n4. Wait for migrations to complete\n\n## ✅ Testing Your Deployment\n\n### Test 1: Frontend Loads\n1. Visit your frontend URL: `https://ai-reviews-web.onrender.com`\n2. Should see \"AI Reviews\" landing page\n3. ✅ If yes, frontend is working\n\n### Test 2: Sign Up\n1. Click \"Sign Up\"\n2. Fill in:\n   - Email: `test@example.com`\n   - Password: `Test123456`\n   - Name: `Test User`\n3. Click \"Create Account\"\n4. ✅ Should redirect to dashboard\n\n### Test 3: Add Business\n1. Click \"Manage Businesses\" or navigate to `/businesses`\n2. Click \"+Add Business\"\n3. Fill in:\n   - Name: `My Test Business`\n   - Category: `Restaurant`\n   - Description: `A test business`\n4. Click \"Create Business\"\n5. ✅ Business should appear in list\n\n### Test 4: Generate Review\n1. Navigate to `/reviews`\n2. Click \"✨ Generate Review\"\n3. Select your business\n4. Leave other settings as default\n5. Click \"Generate Review\"\n6. ✅ Should see generated review appear\n\n### Test 5: Check Analytics\n1. Navigate to `/analytics`\n2. Should see statistics\n3. ✅ All should be working\n\n## 🔧 Troubleshooting\n\n### Frontend Shows 404\n**Problem**: Frontend not loading\n**Solution**:\n1. Check frontend build logs in Render\n2. Make sure build command is correct\n3. Redeploy: Click \"Deployments\" → \"Redeploy\"\n\n### API Calls Return CORS Error\n**Problem**: Console shows CORS error\n**Solution**:\n1. Check backend `CORS_ORIGIN` variable\n2. Should be exact frontend URL (with https://)\n3. Restart backend after changing\n\n### Database Connection Error\n**Problem**: \"Could not connect to database\"\n**Solution**:\n1. Go to PostgreSQL service in Render\n2. Copy connection string again\n3. Update backend `DATABASE_URL` environment variable\n4. Make sure connection string format is correct\n5. Restart backend\n\n### OpenAI API Errors\n**Problem**: \"Invalid API key\" or \"Quota exceeded\"\n**Solution**:\n1. Check OpenAI API key is correct\n2. Go to https://platform.openai.com/account/billing/overview\n3. Verify account has credits\n4. Check rate limits aren't exceeded\n5. Update API key in environment variables\n\n### SignUp/Login Not Working\n**Problem**: Can't create account or login\n**Solution**:\n1. Check backend logs: Go to backend service → \"Logs\"\n2. Check database connection is working\n3. Try running migrations again in shell\n4. Check environment variables are set\n\n## 📊 Monitor Your Deployment\n\n### View Logs\n- Backend: Go to `ai-reviews-api` → \"Logs\"\n- Frontend: Go to `ai-reviews-web` → \"Logs\"\n- Database: Go to `ai-reviews-db` → \"Logs\"\n\n### Redeploy\n1. Go to service\n2. Click \"Deployments\"\n3. Click \"Redeploy\" button\n\n### Update Code\n1. Make changes locally\n2. Push to GitHub: `git push origin main`\n3. Render auto-deploys automatically\n4. Watch deployment progress in Render\n\n## 💰 Costs\n\n- **Frontend**: Free ($0/month)\n- **Backend**: $7/month (minimum paid tier)\n- **Database**: $15/month (minimum PostgreSQL)\n- **Total**: $22/month\n\nNote: Render free tier has limitations.
